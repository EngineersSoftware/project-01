Entra y el panel guarda tu sesión.

El login pide un token al backend. Después, cada pantalla protegida lo envía sola.

  1. Escribes usuario y contraseña.
  2. Spring Boot responde con un JWT.
  3. El navegador lo manda en cada petición privada.
